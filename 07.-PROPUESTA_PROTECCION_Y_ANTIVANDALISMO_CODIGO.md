## 1. INTRODUCCIÓN AL BLINDAJE

Para proteger los meses de trabajo invertidos en el desarrollo de la carátula y el puente de comunicación de la APK, esta propuesta detalla los tres escudos de seguridad física y digital que impiden el robo del código, la clonación del instalador y el acceso no autorizado a través de navegadores de escritorio.

## 2. ESCUDO 1: FILTRADO POR USER-AGENT (FIRMA SECRETA WEB)

Este escudo evita que cualquier persona que conozca el enlace de Render pueda abrir la carátula desde una PC u otro dispositivo fuera de tu APK oficial.

### A. Configuración en la APK (Java - Carpeta 45)
Inyectamos una clave de seguridad exclusiva (Token) dentro del identificador del navegador WebView de la app:

```java
// Archivo: MainActivity.java
// Modificar la configuración de webViewNeon antes de cargar la URL
WebSettings settings = webViewNeon.getSettings();
String defaultUA = settings.getUserAgentString();

// Creamos un User-Agent único agregando una firma secreta
String secretToken = "NeonStudioSecureClient-V1-X98274";
settings.setUserAgentString(defaultUA + " " + secretToken);
```

### B. Validación en el Servidor (Node.js/Express - Carpeta 40)
Configuramos un filtro (Middleware) de seguridad en tu servidor de Render para que verifique si la petición contiene el token de seguridad. Si alguien entra sin el token, el servidor le denegará el acceso.

```typescript
// Archivo: server.ts
// Agregar este filtro al inicio de las rutas del servidor
app.use((req, res, next) => {
  const userAgent = req.headers["user-agent"] || "";
  const secretToken = "NeonStudioSecureClient-V1-X98274";

  // Solo validar en producción para permitir pruebas locales en desarrollo
  if (process.env.NODE_ENV === "production") {
    if (!userAgent.includes(secretToken)) {
      console.warn("[SEGURIDAD] Intento de acceso no autorizado bloqueado.");
      return res.status(403).send("Error 403: Acceso denegado. Esta aplicación web solo es accesible a través de la aplicación oficial.");
    }
  }
  next();
});
```

## 3. ESCUDO 2: OFUSCACIÓN DE CÓDIGO NATIVO (PROGUARD / R8)

Este escudo encripta el código Java de la APK al compilar en Android Studio, impidiendo que hackers puedan descompilar tu app y copiar tus desarrollos.

### A. Configuración en Gradle (Carpeta 45)
Se activa en el archivo de construcción del módulo de la app:  
`app/build.gradle`

```groovy
android {
    ...
    buildTypes {
        release {
            // Activa el optimizador y ofuscador R8
            minifyEnabled true
            // Elimina recursos visuales no utilizados para reducir tamaño
            shrinkResources true
            // Carga las reglas estándar de optimización de Android
            proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'), 'proguard-rules.pro'
        }
    }
}
```

### B. Configuración de Excepciones (`proguard-rules.pro`)
Para evitar que R8 encripté las interfaces Javascript que deben conservar sus nombres exactos (como `AndroidInterface` y `startVoiceCall`), se añade esta regla en el archivo `app/proguard-rules.pro`:

```proguard
# Conservar las anotaciones @JavascriptInterface para que no se rompa el puente de comunicación
-keepattributes JavascriptInterface
-keepclassmembers class * {
    @android.webkit.JavascriptInterface <methods>;
}
```

## 4. ESCUDO 3: FIRMA DIGITAL NATIVA (ANTI-CLONADO DE APK)

Si un clonador logra descompilar la app y reempaquetarla, tendrá que firmarla con su propia firma, ya que no posee tu archivo `firma_neon`.

Podemos agregar una validación en tiempo de ejecución en `MainActivity.java` para que la app compruebe si la firma digital del celular coincide con el Hash de tu firma oficial. Si el hash cambia (APK clonada), la aplicación se auto-destruirá o se bloqueará automáticamente:

```java
// Comprobar la firma en MainActivity.java al arrancar la app
private void verificarFirmaOriginal() {
    try {
        PackageInfo packageInfo = getPackageManager().getPackageInfo(
            getPackageName(), 
            PackageManager.GET_SIGNATURES
        );
        for (Signature signature : packageInfo.signatures) {
            MessageDigest md = MessageDigest.getInstance("SHA");
            md.update(signature.toByteArray());
            String signatureHash = Base64.encodeToString(md.digest(), Base64.DEFAULT).trim();
            
            // Reemplazar con el Hash de tu firma_neon oficial
            String firmaOficialHash = "TUFIRMAOFICIALHASHDEPRODUCCION=";
            
            if (!signatureHash.equals(firmaOficialHash)) {
                // Si el Hash no coincide, es una APK clonada
                Toast.makeText(this, "ERROR: APLICACIÓN CORRUPTA O MODIFICADA.", Toast.LENGTH_LONG).show();
                finish(); // Cierra la app de inmediato
            }
        }
    } catch (Exception e) {
        e.printStackTrace();
    }
}
```

## 5. CONCLUSIÓN Y RECOMENDACIÓN

Al combinar la **Firma Secreta Web (User-Agent)** con la **Ofuscación de Android (R8)** y la **Validación de Firma Nativa**, tu proyecto queda blindado. Los usuarios y competidores solo verán una interfaz funcional de alta gama, y cualquier intento de clonar la APK o usar la web fuera del celular quedará neutralizado al instante.
