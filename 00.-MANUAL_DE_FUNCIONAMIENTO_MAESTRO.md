## 1. ARQUITECTURA GENERAL DEL SISTEMA

La aplicación funciona bajo un modelo híbrido de **doble WebView superpuesto** controlado en un chasis nativo de Android:

```
┌────────────────────────────────────────────────────────┐
│ CAPA 2 (Frente): webViewNeon (Página 1 - React Web)    │ ← Carátula visible, botones y animaciones
├────────────────────────────────────────────────────────┤
│ CAPA 1 (Fondo): webViewStudio (Página 2 - AI Studio)   │ ← Google AI Studio oculto procesando la voz
└────────────────────────────────────────────────────────┘
```

Ambos WebViews se comunican mediante un puente JavaScript nativo (`AndroidInterface`), lo que permite que las acciones del usuario en la carátula web (Capa 2) ejecuten códigos y clics automáticos en la interfaz de Google AI Studio (Capa 1).

## 3. FUNCIONAMIENTO DE LOS BOTONES Y FLUJO DE LLAMADA

### 📹 Botón de Video (Icono de Cámara - Izquierda)
1. El usuario hace clic en el botón de video de la carátula web.
2. React ejecuta `onToggleVoice()` en `App.tsx` y manda llamar a `AndroidInterface.startVoiceCall()` en Java sin parámetros (por defecto es llamada con video).
3. Java inyecta una secuencia automática de clics temporizados (1 segundo de separación) en el DOM de Google AI Studio (`webViewStudio`):
   * **Segundo 1:** Busca y hace clic en el botón de **Webcam** de AI Studio.
   * **Segundo 2:** Busca y hace clic en el botón de **Talk** para iniciar la llamada.
   * **Segundo 3:** Busca y hace clic en el **Micrófono** para abrir el canal de audio.
4. **Estado visual:** El botón de la cámara se enciende en color verde brillante en la carátula, mientras que el teléfono permanece dorado apagado.

### 📞 Botón de Audio (Icono de Teléfono - Derecha)
1. El usuario hace clic en el botón del teléfono de la carátula web.
2. React ejecuta `onToggleAudio()` en `App.tsx` y manda llamar a `AndroidInterface.startVoiceCall(false)` (el parámetro `false` indica llamada de solo voz).
3. Java recibe el indicador `false` y ejecuta **inmediatamente y únicamente el Segundo 2 (clic en "Talk")** en Google AI Studio. Se salta los pasos de Webcam y de Micrófono secundario.
4. **Estado visual:** El botón del teléfono se ilumina en color rojo, **el icono del teléfono rota 135 grados** (posición de colgar) y se activa un pulso de onda roja. El botón de la cámara permanece dorado apagado.

### ⏹️ Colgar Llamada (Cualquiera de los dos botones)
1. Al presionar el botón activo (el verde de video o el rojo de audio), se manda llamar a `AndroidInterface.endVoiceCall()` en Java.
2. Java inyecta un script en `webViewStudio` para extraer las transcripciones de texto de la conversación y enviarlas de regreso a la memoria diaria de la carátula.
3. Finalmente, Java ordena `webViewStudio.reload()`, lo cual recarga la página de Google AI Studio, cortando instantáneamente la transmisión WebRTC de audio y video.
4. **Estado visual:** Ambos botones se apagan y regresan a su color dorado metálico.

## 4. FLUJO DE ACTUALIZACIÓN Y DESPLIEGUE

### 🌐 Actualizaciones Web (Capa de la carátula en la Carpeta 40)
Cualquier cambio de diseño, botones, colores o lógica React se sube de la siguiente manera:
1. Compilar localmente para asegurar que no haya errores: `npm run build`
2. Subir los cambios a GitHub:
   ```bash
   git add .
   git commit -m "Descripción del cambio"
   git push origin main
   ```
3. Render.com detecta el push en GitHub y actualiza automáticamente el sitio web en vivo en 2 minutos. **No necesitas recompilar la APK de Android para cambios visuales.**

### 🤖 Actualizaciones de la APK (Capa nativa en la Carpeta 45)
Cualquier cambio en el puente Java, permisos del celular o carga de capas se realiza así:
1. Abrir la carpeta `45.-APK STUDIO NEON VIDEO` en Android Studio.
2. Realizar los cambios en `MainActivity.java` o `activity_main.xml`.
3. Ir a **Build -> Generate Signed Bundle / APK**.
4. Seleccionar la firma `firma_neon` ubicada en la raíz de la carpeta 45.
5. Instalar la nueva APK generada en el celular.
