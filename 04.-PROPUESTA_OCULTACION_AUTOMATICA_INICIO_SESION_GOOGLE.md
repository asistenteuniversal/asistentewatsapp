# 🔒 04.- PROPUESTA Y GUÍA TÉCNICA: Ocultación Automática de Inicio de Sesión de Google
**Fecha:** 11 de Agosto de 2026  
**Proyecto:** NEON STUDIO ANDROIT — Integración de Capas (APK nativa)  
**Ubicación:** Carpeta 40 (Web) y Carpeta 45 (Android)

---

## 1. OBJETIVO DE LA PROPUESTA

El objetivo de esta propuesta es mejorar la experiencia del cliente final al ocultar por completo la interfaz técnica de desarrollo de **Google AI Studio** (prompts, cuadros de texto de desarrollo, paneles laterales, etc.) y conservar un inicio de sesión 100% seguro contra bloqueos de Google y compatible con verificación en dos pasos (2FA).

El cliente solo verá el inicio de sesión oficial de Google la primera vez que abra la app, y en el instante en que inicie sesión, entrará directamente a la carátula premium de Neon, sin enterarse jamás de que Google AI Studio se ejecuta en el fondo.

## 3. CÓDIGO DE IMPLEMENTACIÓN JAVA (EN FOLDER 45)

Este cambio se realiza **exclusivamente dentro de la APK (Carpeta 45)**, modificando el comportamiento del `WebViewClient` nativo en el archivo:  
`app/src/main/java/com/phantomlink/neonstudio/MainActivity.java`

No afecta a ningún archivo del proyecto web de React (Carpeta 40).

### Fragmento de Código Java a implementar:

```java
// Configuración de visibilidad inteligente de capas en MainActivity.java
public void setupWebViewSessionMonitor() {
    
    // Asignar el WebViewClient a la capa de Google AI Studio
    webViewStudio.setWebViewClient(new WebViewClient() {
        
        @Override
        public void onPageStarted(WebView view, String url, Bitmap favicon) {
            super.onPageStarted(view, url, favicon);
            
            // 1. Si la URL es de Login de Google, traer a primer plano el WebView de Google
            if (url.contains("accounts.google.com")) {
                runOnUiThread(new Runnable() {
                    @Override
                    public void run() {
                        // Trae a la pantalla el inicio de sesión oficial
                        webViewStudio.setVisibility(View.VISIBLE);
                        webViewNeon.setVisibility(View.GONE);
                        Log.d("NEON_SESSION", "Detectado Login de Google. Mostrando WebViewStudio.");
                    }
                });
            }
        }

        @Override
        public void onPageFinished(WebView view, String url) {
            super.onPageFinished(view, url);
            
            // 2. Si la URL entra a AI Studio (inicio de sesión exitoso)
            if (url.contains("aistudio.google.com")) {
                runOnUiThread(new Runnable() {
                    @Override
                    public void run() {
                        // Ocultar Google AI Studio al instante
                        webViewStudio.setVisibility(View.GONE);
                        
                        // Mostrar la carátula Neon al frente del usuario
                        webViewNeon.setVisibility(View.VISIBLE);
                        Log.d("NEON_SESSION", "Sesión iniciada con éxito. Ocultando WebViewStudio.");
                        
                        // Opcional: Lanzar callback en la carátula web para activar la IA
                        webViewNeon.evaluateJavascript("if(window.onGoogleSessionReady) { window.onGoogleSessionReady(); }", null);
                    }
                });
            }
        }
    });
}
```

## 4. MAQUETACIÓN DEL LAYOUT XML (`activity_main.xml`)

Para que la superposición y ocultación funcionen correctamente, los dos WebViews deben ocupar toda la pantalla y declararse superpuestos en el archivo XML:

```xml
<?xml version="1.0" encoding="utf-8"?>
<FrameLayout xmlns:android="http://schemas.android.com/apk/res/android"
    android:layout_width="match_type"
    android:layout_height="match_type">

    <!-- CAPA 1 (Fondo): Google AI Studio -->
    <WebView
        android:id="@+id/webViewStudio"
        android:layout_width="match_parent"
        android:layout_height="match_parent"
        android:visibility="gone" />

    <!-- CAPA 2 (Frente): Carátula Dorada de Neon -->
    <WebView
        android:id="@+id/webViewNeon"
        android:layout_width="match_parent"
        android:layout_height="match_parent"
        android:visibility="visible" />

</FrameLayout>
```

## 5. BENEFICIOS CLAVE DE ESTE DISEÑO
1. **Confianza y Seguridad:** El usuario escribe su contraseña en la pasarela oficial y segura de Google (con soporte para verificación en dos pasos por SMS o App).
2. **Cero Bloqueos:** Al no inyectar contraseñas mediante Javascript, Google nunca detecta la app como un bot malicioso.
3. **Estética Limpia:** El panel técnico de desarrollo de Google queda bloqueado a la vista. El cliente final experimenta una app donde solo ve el inicio de sesión y de inmediato la carátula dorada.
