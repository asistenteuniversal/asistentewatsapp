**Proyecto:** NEON STUDIO ANDROIT — Control y Seguridad de Clientes  
**Ubicación:** Carpeta 40 (Web) y Carpeta 45 (Android)

---

## 1. OBJETIVO DE LA PROPUESTA

Esta propuesta detalla el diseño de seguridad para permitirte activar, suspender o bloquear de forma remota e inalámbrica el uso de la aplicación en el celular de tus clientes desde tu PC. 

Esto se logra manipulando el archivo de configuración central en tu servidor web, sin necesidad de compilar nuevas versiones nativas de la APK en Android.

---

## 2. ESQUEMA DE CONFIGURACIÓN DEL ARCHIVO CENTRAL (`asistente_config.json`)

Para habilitar este control, el archivo de configuración en tu PC se estructuraría de la siguiente manera:

```json
{
  "systemInstructions": "Eres un asistente de voz...",
  "globalStatus": "active",
  "globalBlockedMessage": "SISTEMA FUERA DE SERVICIO TEMPORALMENTE. CONTACTE A SOPORTE.",
  "authorizedClients": [
    "cliente_premium",
    "empresa_avantar",
    "usuario_01"
  ]
}
```

* **`globalStatus`**: Puede ser `"active"` (activo) o `"blocked"` (bloqueado globalmente).
* **`authorizedClients`**: Lista de identificadores de clientes que tienen su suscripción activa.

---

## 3. INTEGRACIÓN EN LA CAPA WEB DE REACT (PROPUESTA DE CÓDIGO)

Cuando implementemos este cambio en la carpeta 40, la aplicación en el celular validará las credenciales al arrancar. Si el sistema está bloqueado, el código interrumpirá el renderizado normal y mostrará una pantalla negra de bloqueo con estética premium (bordes dorados).

### Fragmento de lógica de validación en `App.tsx`:

```typescript
// Variables de control de bloqueo
const [isBlocked, setIsBlocked] = useState(false);
const [blockedMessage, setBlockedMessage] = useState('');

useEffect(() => {
  fetch('/asistente_config.json')
    .then((res) => res.json())
    .then((data) => {
      // 1. Extraer el cliente desde el enlace del celular (ejemplo: ?cliente=usuario_01)
      const params = new URLSearchParams(window.location.search);
      const currentClient = params.get('cliente');

      // 2. Comprobar bloqueo global
      if (data.globalStatus === 'blocked') {
        setIsBlocked(true);
        setBlockedMessage(data.globalBlockedMessage || 'APLICACIÓN INACTIVA POR LICENCIA.');
        return;
      }

      // 3. Comprobar autorización individual por cliente
      if (currentClient && data.authorizedClients) {
        if (!data.authorizedClients.includes(currentClient)) {
          setIsBlocked(true);
          setBlockedMessage('ACCESO RECHAZADO: LICENCIA INACTIVA O VENCIDA PARA ESTE DISPOSITIVO.');
        }
      }
    })
    .catch((err) => console.error('Error validating remote license status:', err));
}, []);
```

## 4. ADMINISTRACIÓN DESDE EL ESCRITORIO DE TU PC

Para que no tengas que abrir código al bloquear o desbloquear clientes, se creará un cuadro negro ejecutable en tu PC: **`BLOQUEAR_O_ACTIVAR_CLIENTES.bat`**.

### Flujo del script en tu PC:
1. Das doble clic al script.
2. Abre un cuadro de opciones:
   * **[1]** Bloquear la aplicación a TODOS los clientes.
   * **[2]** Desbloquear la aplicación a TODOS los clientes.
   * **[3]** Agregar nuevo cliente autorizado.
   * **[4]** Eliminar/Bloquear un cliente específico.
3. Elige la opción y el script modifica el archivo JSON, corre la compilación de seguridad de React, hace el push a GitHub y actualiza los celulares de todo el mundo en vivo en 2 minutos.
