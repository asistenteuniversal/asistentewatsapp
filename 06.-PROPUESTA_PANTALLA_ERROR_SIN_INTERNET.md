# 📡 06.- PROPUESTA Y GUÍA TÉCNICA: Pantalla de Error Personalizada sin Internet (Modo Offline)
**Fecha:** 11 de Agosto de 2026  
**Proyecto:** NEON STUDIO ANDROIT — Experiencia de Usuario Offline  
**Ubicación:** Carpeta 40 (Web) y Carpeta 45 (Android)

---

## 1. OBJETIVO DE LA PROPUESTA

Cuando el celular se queda sin señal o abre la aplicación sin internet, por defecto el navegador WebView de Android muestra una página en blanco genérica con el mensaje `"Página web no disponible" (net::ERR_NAME_NOT_RESOLVED)`. Esta pantalla rompe el diseño premium del producto y expone que la aplicación depende de una dirección web.

La propuesta consiste en interceptar este fallo de conexión de manera nativa en Java y redirigir el WebView a un archivo HTML de diseño local que cargará instantáneamente sin necesidad de señal de internet, manteniendo el fondo negro mate y las letras doradas de Neon en todo momento.

## 3. CÓDIGO NATIVO JAVA A IMPLEMENTAR (EN FOLDER 45)

Este código intercepta los errores del navegador y carga el archivo HTML local en lugar de la pantalla blanca. Se agrega en el archivo `MainActivity.java` de la APK:

```java
// Modificación del WebViewClient en MainActivity.java
webViewNeon.setWebViewClient(new WebViewClient() {
    
    // Método para interceptar fallos de carga en Android 6.0 o superior
    @Override
    public void onReceivedError(WebView view, WebResourceRequest request, WebResourceError error) {
        super.onReceivedError(view, request, error);
        
        // Solo interceptar si el fallo ocurre en la página principal, no en archivos JS/CSS menores
        if (request.isForMainFrame()) {
            runOnUiThread(new Runnable() {
                @Override
                public void run() {
                    // Cargar el HTML offline local guardado en la APK
                    view.loadUrl("file:///android_asset/error.html");
                    Log.d("NEON_OFFLINE", "Detectada falta de internet. Cargando error.html.");
                }
            });
        }
    }
    
    // Método para compatibilidad con versiones antiguas de Android
    @SuppressWarnings("deprecation")
    @Override
    public void onReceivedError(WebView view, int errorCode, String description, String failingUrl) {
        super.onReceivedError(view, errorCode, description, failingUrl);
        runOnUiThread(new Runnable() {
            @Override
            public void run() {
                view.loadUrl("file:///android_asset/error.html");
            }
        });
    }
});
```

## 4. INSTRUCCIONES DE VERIFICACIÓN

1. Guarda el archivo `error.html` en la ruta `app/src/main/assets/` dentro del proyecto en Android Studio.
2. Añade los dos métodos `onReceivedError` en tu archivo `MainActivity.java` dentro del configurador del `webViewNeonClient`.
3. Compila la APK e instálala en tu celular.
4. **Prueba 1 (Sin señal):** Pon tu celular en Modo Avión o apaga el Wi-Fi/Datos móviles y abre la aplicación. En lugar de la pantalla blanca, aparecerá instantáneamente la pantalla Neon negra con el logotipo dorado de antena y el botón "REINTENTAR".
5. **Prueba 2 (Recuperación de señal):** Enciende el Wi-Fi o Datos y presiona el botón dorado "REINTENTAR". El sistema recargará la carátula dorada de forma normal.
